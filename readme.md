# Bubsy 1 Genesis music dumper

quick tiny script i threw together to convert the music from a USA Genesis copy of Bubsy 1 to MIDI files. 
should theoretically work for [other games using the same sound driver](https://vgmpf.com/Wiki/index.php?title=Mega_Drive/Genesis_Sound_Driver_List#Accolade.2FRussell_Shiffer) if you give it the right addresses

usage:
```bubsymusdump.py [ROM PATH]```

big thanks to Valley Bell for figuring out basically the whole format
